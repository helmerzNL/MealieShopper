# Lettertypen

Lokaal geladen, geen verbinding met een externe fontdienst.

| Bestand | Gebruik | Licentie |
| --- | --- | --- |
| `Manrope-Variable.woff2` | Koppen en woordmerk (gewicht 200-800), subset latin | `OFL-Manrope.txt` |
| `Manrope-Variable.ttf` | Volledige variabele font; reservebron voor het web en invoer voor `scripts/build_brand.py` | `OFL-Manrope.txt` |
| `Inter-Variable.woff2` | Interface en lopende tekst (gewicht 100-900), subset latin | `OFL-Inter.txt` |

Beide lettertypen vallen onder de SIL Open Font License 1.1. De woff2-bestanden zijn de
latin-subset uit de npm-pakketten `@fontsource-variable/manrope` en `@fontsource-variable/inter`
(versie 5.1.0); de TTF komt uit de Google Fonts-repository (`ofl/manrope`).
